# App languages, Files and memory — native build 7

The app UI supports Portuguese, English, Spanish, French, German, Italian and Japanese. Choose Settings → App language; System follows supported preferred languages, then English. Changes apply to native home/settings and mobile action labels immediately. This does not change console language, game text, audio or content. Translation keys are app-owned UI text; `python3 tools/check_app_localization.py` validates coverage and format placeholders.

Existing `Library/Application Support/Game` installations migrate to `Documents/Game`, which is exposed by the existing file-sharing and open-in-place Info.plist flags. On iPhone, use Files → On My iPhone → Storm Native → Game. Migration uses Darwin `renamex_np(..., RENAME_EXCL)` on the same app volume, avoiding a multi-GB copy and refusing conflicts. It runs before configuring the runtime game path and before importer validation. App updates keep the bundle identifier and save location. Editing game files requires closing the app. Saves remain in Application Support/User. No new import is required for an existing valid installation.

Expanded memory defaults on in response to the owner's request. `runtime.title_memory_mb=0` is the pinned SDK's documented way to remove its title commit-budget cap. Disabling the option restores 512 MiB in compatible profiles or 480 MiB in Standard. This does not enlarge Xbox physical address ranges, reserve all physical iPhone RAM, bypass iOS memory limits or add an entitlement unsupported by AltStore provisioning. Texture-cache limits become 384/512 MiB instead of 256/384. The app also declares `GCSupportsGameMode` and its game category; iOS decides whether Game Mode activates. No measured performance gain is claimed.

Build-6 device evidence establishes Safe/full resolve, synchronous memexport, 720p, 1× and FXAA off. The last 60 reported presentation samples average 14.12 FPS, min 2, max 23; this is not a controlled fight benchmark. Low Power Mode was off, thermal state fair, available process memory about 1993 MiB and zero app memory warnings. Separate crashes show an optional debugger thread-name notification aborting in host thread-name string assignment and an invalid null resource-table entry. These are not evidence that Fast caused this user's crashes. A narrow private wrapper ignores only the optional 0x406D1388 debugger thread-name notification (flags 0, four parameters); the title already has generated thread names. All other guest exceptions are forwarded unchanged. The resource hook records failing resource coordinates and flushes. It does not skip resource processing, fabricate allocations or map guest page zero. Reports add actual process physical footprint and available process memory per sample. Crash resolution and FPS gains need device validation.

The UIKit smoke checks exercise all seven app languages while proving that runtime configuration remains unchanged by language selection, the existing input sequences, expanded-memory settings, and atomic import migration including inode identity, contents, idempotence and conflicts. Static IPA inspection verifies packaging only. Native execution still requires the user's physical iPhone.
